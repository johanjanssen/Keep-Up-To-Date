Native Images

🧬 Runtime-Based vs. Native Image

Runtime-based

  • 📦Ship intermediate code plus a runtime (VM / interpreter)
  • ⏳Loads and optimizes code on every start
  • 🔄Fully dynamic at runtime

Native image

  • ⚙️Compile app + libraries ahead of time into one executable
  • ✂️Unused code from app, libraries and runtime is left out
  • 🚀Instant start, small footprint; patching means rebuilding

The price: slower builds · a binary per OS/CPU · reflection must be declared up front
