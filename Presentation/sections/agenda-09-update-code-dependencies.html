Update Code Dependencies

Which Dependencies Are Outdated?

Compare with the latest releases, without changing anything

  • 📦npm outdated (Node.js)
  • 🐍pip list --outdated (Python)
  • 🟣dotnet list package --outdated (.NET)

☕ Discover Stale Dependencies: Maven

☕ Maven Versions Plugin (Java) 
./mvnw versions:display-dependency-updates

# [INFO] org.postgresql:postgresql ...... 42.7.3 -> 42.8.0
# [INFO] jackson-databind .............. 2.17.1 -> 2.18.2
# [INFO] log4j-core .................... 2.0    -> 2.24.3  ← 🔴 CVE!
Gradle equivalent: com.github.ben-manes.versions plugin → ./gradlew dependencyUpdates
Also useful: ./mvnw versions:display-plugin-updates (build plugins) and ./mvnw versions:display-property-updates (${my.version} properties).

Use a Bill of Materials (BOM)

  • 📋A curated, tested set of dependency versions
  • ⬆️One version bump instead of dozens of decisions
  • ✅The maintainer verifies the versions work together

BOM Example: Spring Boot

☕ Java example: Spring Boot parent POM 
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>4.1.0</version>
</parent>
Also upgrades: Jackson · Tomcat · Netty · Hibernate · Micrometer · Logback …

When a Dependency Gets a New Name

The old coordinates stop getting releases, so "latest version" checks stay silent

🪦 Java EE (old)

<groupId>javax.servlet</groupId>
<artifactId>javax.servlet-api</artifactId>
<version>4.0.1</version>
import javax.servlet.http.HttpServlet;

🌱 Jakarta EE (new)

<groupId>jakarta.servlet</groupId>
<artifactId>jakarta.servlet-api</artifactId>
<version>6.1.0</version>
import jakarta.servlet.http.HttpServlet;

Catch Deprecated & Renamed Packages

🌐 Renovate replacements presets (generic) 
{ "extends": ["replacements:all"] }
// e.g. auto-PRs "org.json:json" -> its maintained replacement
docs.renovatebot.com/presets-replacements
☕ Old GroupIds Alerter (OGA, Java) Warns when a Maven groupId moved, e.g. javax.* → jakarta.* 
./mvnw biz.lermitage.oga:oga-maven-plugin:1.9.2:check \
       -DfailOnError=false   # report only
