Update or Remove

Benefits of Removing or Updating

  • Security
  • Maintainability
  • Upgradability
  • Lots more words ending in -ity
  • Reduced resource consumption
  • Performance
  • Adherence to laws and regulations
  • Saving money

Prevent Security Vulnerabilities

  • Software you don't deploy can't be hacked
  • If you do deploy something, make sure you automatically upgrade it on a schedule, and keep the ability to trigger an upgrade manually

Detect Dead Code in Production

Code coverage in CI tells you what your tests exercise. Coverage from a production agent tells you what real users actually call — revealing removal candidates.
