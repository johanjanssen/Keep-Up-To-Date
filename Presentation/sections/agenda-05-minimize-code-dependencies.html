Chapter 05

Minimize Code Dependencies

📦 The Dependency Graph Problem

  • 🧑‍💻You choose the direct dependencies, but you're responsible for the transitive ones too
  • 🕸️Every node: a possible CVE, breaking change or license issue
  • 🚫Unmanageable without tooling

Use a Bill of Materials (BOM)

  • 📋A curated, tested set of dependency versions
  • ⬆️One version bump instead of dozens of decisions
  • ✅The maintainer verifies the versions work together

BOM Example: Spring Boot

☕ Java example: Spring Boot parent POM 
<parent>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>4.1.0</version>
</parent>
Also upgrades: Jackson · Tomcat · Netty · Hibernate · Micrometer · Logback …

Keep the Dependency List Honest

  • 🗑️Declared but unused: remove it
  • 👻Used but undeclared: declare it, don't rely on luck
  • 🚫Known-bad libraries: ban them
  • 🛑Let the build fail, so it stays that way

Find Unused Dependencies

☕ Maven Dependency Plugin (Java) 
./mvnw dependency:analyze

# [WARNING] Unused declared dependencies found:
# [WARNING] org.postgresql:postgresql:jar:42.7.3:compile
# [WARNING] Used undeclared dependencies found:
# [WARNING] com.fasterxml.jackson.core:jackson-core:jar:2.18.2:compile

Fail the Build on Unused Dependencies

☕ Maven Dependency Plugin (Java) 
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-dependency-plugin</artifactId>
    <version>3.11.0</version>
    <configuration>
        <failOnWarning>true</failOnWarning>
        <ignoredUnusedDeclaredDependencies>
            <!-- e.g. a JDBC driver only loaded via reflection -->
            <ignoredUnusedDeclaredDependency>
                org.postgresql:postgresql
            </ignoredUnusedDeclaredDependency>
        </ignoredUnusedDeclaredDependencies>
    </configuration>
</plugin>
Gradle equivalent: the com.autonomousapps.dependency-analysis plugin.

Ban Specific Dependencies

Block known-bad libraries before they enter the build

☕ Maven Enforcer Plugin (Java) 
<rules>
    <requireJavaVersion><version>[21,)</version></requireJavaVersion>
    <bannedDependencies>
        <excludes>
            <exclude>log4j:log4j</exclude>         <!-- Log4j 1.x -->
            <exclude>commons-logging:commons-logging</exclude>
        </excludes>
    </bannedDependencies>
</rules>
Gradle equivalent: dependency exclude rules + a version catalog to pin allowed versions.
