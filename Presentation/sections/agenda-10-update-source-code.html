🛠️ What Is OpenRewrite?

☕ Java example

A refactoring engine, not a text-based find/replace

  • 🌳Understands your code: a type-aware syntax tree, not text
  • 📦Recipes compose: "Upgrade to Spring Boot 4" runs dozens of smaller ones
  • 🔍Dry-run first: review the diff before applying

☕ OpenRewrite: Languages & Formats

  • 💻Languages: Java, Kotlin, Groovy, plus early Python support
  • 📄Formats: XML, YAML, JSON, Properties files, Protobuf
  • 📚Recipe libraries: Spring, Jakarta EE, JUnit, Hibernate, Micronaut, Quarkus, and more

🛠️ Alternatives to OpenRewrite

Within the JVM, and beyond it

  • ☕Error Prone + Refaster: bug checks and template-based rewrites
  • 🏢Moderne: OpenRewrite across thousands of repos
  • 🖱️IDE migrations: powerful, but manual and per project

Running OpenRewrite: The Command

☕ OpenRewrite (Java) 
# run from OpenRewrite/: plugin + recipes as -D properties, nothing baked into pom.xml
# (swap :run for :dryRun to preview the changes without modifying any files)
../mvnw -U org.openrewrite.maven:rewrite-maven-plugin:6.46.1:run \
  "-Drewrite.recipeArtifactCoordinates=\
org.openrewrite.recipe:rewrite-static-analysis:2.41.0,\
org.openrewrite.recipe:rewrite-testing-frameworks:3.44.0,\
org.openrewrite.recipe:rewrite-migrate-java:3.42.0,\
org.openrewrite.recipe:rewrite-spring:6.37.1,\
org.openrewrite.recipe:rewrite-java-security:3.38.1" \
  "-Drewrite.activeRecipes=\
org.openrewrite.java.format.AutoFormat,\
org.openrewrite.staticanalysis.EqualsAvoidsNull,\
org.openrewrite.java.testing.junit5.JUnit4to5Migration,\
org.openrewrite.java.migrate.UpgradeToJava25,\
org.openrewrite.java.spring.boot4.UpgradeSpringBoot_4_0,\
org.openrewrite.java.security.FixSqlInjectionConcat"
