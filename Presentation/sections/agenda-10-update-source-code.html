Automate the Migration Itself

When a framework or language version change requires code edits, automated migration tools can apply the changes — consistently and at scale across your whole codebase.

☕ OpenRewrite Recipe-driven, AST-level refactoring. No pom.xml plugin config needed — the plugin and its recipes are supplied entirely on the Maven command line.

# the raw Maven invocation — plugin + recipes as -D properties, nothing baked into pom.xml
./mvnw org.openrewrite.maven:rewrite-maven-plugin:6.46.1:run \
  -Drewrite.recipeArtifactCoordinates=org.openrewrite.recipe:rewrite-spring:6.37.0,... \
  -Drewrite.activeRecipes=org.openrewrite.java.spring.boot4.UpgradeSpringBoot_4_0,...

# wrapped by the demo script (swap :run for :dryRun to preview only):
DRY_RUN=true bash OpenRewrite/scripts/run-openrewrite.sh  # preview
bash OpenRewrite/scripts/run-openrewrite.sh               # apply
