How Do You Find Dead Code?

  • 💡Your IDE finds the simple cases
  • 🤔An unused REST endpoint? Remove it, the code behind it and maybe some libraries
  • ❓But how do you know it's unused in a large application?

Measure Which Code Runs

  • 📊Record which code executes under real or realistic traffic
  • 💤Never executed in weeks? Candidate for removal

Measuring Code Usage

☕ Java example
  • 💼Commercial: Azul Code Inventory measures usage in production
  • ☕Free: a JaCoCo agent attached to your application
  • ⚠️JaCoCo adds overhead: best with acceptance tests in a test environment

☕ How a JaCoCo Agent Measures Coverage

Attach a probe to the running JVM: no code changes needed

☕ Retrieve Coverage via TCP (1/2)

☕ JaCoCo TCP agent (Java): the app keeps running 
# 1: Build the JAR (once per code change)
./mvnw package

# 2: Terminal 1: start the app WITH the agent (keep it running)
AGENT="output=tcpserver,port=6300,includes=com.example.*"
java "-javaagent:jacocoagent.jar=$AGENT" \
     -jar target/jacoco-demo-0.0.1-SNAPSHOT.jar

☕ Retrieve Coverage via TCP (2/2)

☕ JaCoCo TCP agent (Java): the app keeps running 
# 3: Terminal 2: call the REST endpoints
# 4: Terminal 2: dump live coverage from the running JVM
java -jar jacoco-cli.jar dump --address localhost --port 6300 \
     --destfile target/jacoco-live.exec --reset

# 5: Terminal 2: generate the HTML report
java -jar jacoco-cli.jar report target/jacoco-live.exec \
     --classfiles target/classes --sourcefiles src/main/java \
     --html target/coverage-report

--reset: repeat steps 3–5 for fresh snapshots, no restart
