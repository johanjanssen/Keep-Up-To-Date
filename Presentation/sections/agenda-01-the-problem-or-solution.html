🚨 Many Dependencies

  • 🧩Every application has direct and transitive dependencies, often hundreds
  • 🎲Potential Common Vulnerabilities and Exposures (CVEs)

The Compounding Cost of Delay

  • 🔐Security: each skipped version = another version to jump over when a CVE forces your hand
  • ⚡Performance: runtime improvements accumulate; you leave free speed on the table
  • 🧗Migration effort: small incremental hops are easy; multi-year jumps require dedicated projects

🔍 Different Tools

Where each of today's scanners actually looks

Layer 1: Source / Build

  • ☕OWASP Dependency Check: manifest only, NVD database
  • 🌐OSV-Scanner: lockfiles & SBOMs, OSV.dev database

Layer 2: Runtime / Image

  • 🌐Grype: built image, Anchore's own feed
  • 🌐Trivy: built image, widest DB + secrets/misconfig
  • 🌐OSV-Scanner: built image too, same OSV.dev database

Layer 1: Source-Level Scanning

☕ OWASP Dependency Check (Java)

Analyzers for Java (Maven/Gradle), .NET, Node.js, Python and others; this demo uses the Maven plugin.

<plugin>
    <groupId>org.owasp</groupId>
    <artifactId>dependency-check-maven</artifactId>
    <configuration>
        <failBuildOnCVSS>7</failBuildOnCVSS>  <!-- fail on HIGH+ -->
    </configuration>
</plugin>
./mvnw dependency-check:check
# log4j-core-2.0.jar      → CVE-2021-44228 CRITICAL 10.0 🔴
# jackson-databind-2.9.10 → CVE-2019-14379 CRITICAL  9.8 🔴

Layer 2: Image / Artifact Scanning

🌐 Trivy (Aqua) 
trivy image eclipse-temurin:25-jre
trivy image --format sarif --output trivy-results.sarif eclipse-temurin:25-jre
trivy image --severity HIGH,CRITICAL --exit-code 1 eclipse-temurin:25-jre
🌐 Grype (Anchore) 
grype eclipse-temurin:25-jre
grype eclipse-temurin:25-jre -o sarif > grype-results.sarif
grype eclipse-temurin:25-jre --fail-on high

OSV-Scanner Operates on Both Layers

One CLI that reads lockfiles, SBOMs and images across 20+ ecosystems, all against the same open OSV database.

🌐 osv-scanner 
osv-scanner scan source --lockfile=pom.xml .
osv-scanner scan image eclipse-temurin:25-jre
osv-scanner scan --sbom=target/bom.json .
