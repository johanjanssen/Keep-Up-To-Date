🤖 But... What About AI?

AI coding assistants are genuinely useful here — but they change how you do this work, not whether you need to.

  • Copilot / Claude can draft the code changes a major-version bump requires — you still need tests to trust the diff
  • AI can summarise a changelog or a CVE advisory in seconds — it can also hallucinate a "safe" summary of a breaking change
  • Agentic tools can open and iterate on update PRs — the safety net (tests, scanners, enforcer rules) is still what lets you trust the merge
💡 AI is a force multiplier on top of the practices in this talk — pinned versions, tests, scanning, SBOMs — not a replacement for them. Garbage in, confidently-wrong-sounding garbage out.
