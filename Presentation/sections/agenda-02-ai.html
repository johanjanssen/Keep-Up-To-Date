☕ Java example Ask an LLM for a Spring Security config and it may still suggest @EnableGlobalMethodSecurity: deprecated in 5.6, removed in Spring Security 6. The replacement, @EnableMethodSecurity, postdates its training data.

🪞 This Deck Practices What It Preaches

Every demo in this repository — the scanners, the Docker image ladder, the Renovate bot, even these slides — was built and iterated on with an agentic coding tool (Claude Code) doing the legwork, with a human reviewing every change.

Not a claim that it's magic: the same "verify before you trust it" rule from the previous slides applied here too.
