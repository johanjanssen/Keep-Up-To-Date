Native Images vs. Checkpoint/Restore

🧬 What Is a Native Image?

Do the compiling at build time, not every time the app starts

Runtime-based

  • 📦Ship intermediate code plus a runtime (VM / interpreter)
  • ⏳Loads and optimizes code on every start
  • 🔄Fully dynamic at runtime

Native image

  • ⚙️Compile app + libraries ahead of time into one executable
  • ✂️Unused code from app, libraries and runtime is left out
  • 🚀Instant start, small footprint, no runtime to patch

The price: slower builds · a binary per OS/CPU · reflection must be declared up front

🧱 Anatomy of a Container Image

Native images skip the runtime layer

⏸️ What Is Checkpoint/Restore?

Start once, snapshot, restore many times

  • 🔥Start and warm up the app once
  • 📸Snapshot the running process to disk
  • ⚡Restore in milliseconds, already warmed up
  • ⚠️Watch out: secrets and open connections end up in the snapshot
