Which Runtime Distribution?

Most ecosystems have multiple vendors distributing the same runtime — all standards-compliant, but trading off differently on image size, tooling, and support model.

⚖️ jlink vs GraalVM native-image vs CRaC

Three ways to fix "JVM cold-start is slow" — different tradeoffs

ApproachStartupBuild timeCompatibilityPeak throughput
jlink JRENormal JVM (~1–2s)FastFull — still the real JVMFull JIT, best long-run throughput
GraalVM native-image~10–50msSlow — full AOT compileReflection/dynamic-proxy config neededNo JIT — good but not peak HotSpot
Azul CRaC checkpoint/restore~50–100msExtra checkpoint step in the pipelineRuns regular JVM bytecode unmodifiedFull JIT, resumes already-warmed-up

CRaC's tradeoff isn't compatibility — it's operational: the checkpoint captures process state (open sockets, files) at a point in time, so you design your startup code around what's safe to snapshot.
